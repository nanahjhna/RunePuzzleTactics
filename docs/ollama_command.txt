OpenCode 터미널 환경에서 사용할 수 있는 주요 명령어 및 슬래시(/) 명령어 모음입니다.

opencode

* **`/connect`**
* Ollama 등 로컬 LLM 제공자를 연결하거나 설정을 변경할 때 사용합니다.


* **`/help`**
* 현재 사용 가능한 명령어 목록과 도움말을 화면에 출력합니다.


* **`/clear`**
* 현재 대화 기록을 초기화하여 새로운 맥락에서 대화를 시작할 수 있습니다.


* **`/exit` 또는 `/quit**`
* OpenCode 프로그램을 종료하고 터미널로 빠져나갑니다.


Ollama를 터미널(PowerShell 또는 명령 프롬프트)에서 다룰 때 가장 자주 쓰는 핵심 명령어 목록입니다.

* **모델 다운로드 (설치)**
* 명령어: `ollama pull <모델이름>`
* 설명: 지정한 로컬 LLM을 내 컴퓨터로 다운로드합니다. (예: `ollama pull qwen2.5-coder:1.5b`)
ollama pull llama3.1:8b

* **설치된 모델 목록 확인**
* 명령어: `ollama list`
* 설명: 현재 내 컴퓨터에 다운로드되어 있는 모든 로컬 모델의 목록과 용량, 수정일을 보여줍니다.


* **모델 실행 및 대화 (터미널 직접 대화)**
* 명령어: `ollama run <모델이름>`
* 설명: 다운로드한 모델을 실행하여 터미널 창에서 곧바로 AI와 대화를 나누거나 테스트할 수 있습니다. (종료하려면 `/exit` 입력)


* **다운로드한 모델 삭제**
* 명령어: `ollama rm <모델이름>`
* 설명: 더 이상 쓰지 않는 모델을 삭제하여 컴퓨터 용량을 확보합니다.


* **Ollama 백그라운드 서비스 종료**
* 명령어: `ollama stop` (또는 작업 관리자 및 우측 하단 트레이 아이콘에서 종료)
* 설명: 백그라운드에서 실행 중인 Ollama 엔진을 완전히 끕니다.


OpenCode 인터페이스 안에서 작업 효율을 높여주는 주요 단축키와 명령어 모음입니다.

**핵심 단축키**

* **`Ctrl + P`**: 전체 명령어 메뉴(Command Palette)를 열어 다양한 기능을 빠르게 실행할 수 있습니다.
* **`Tab`**: 에이전트 모드를 전환합니다. (예: 분석 및 계획 위주의 `Plan` 모드와 실제 코드 수정 위주의 `Build` 모드 간 이동)
* **`Esc`**: 현재 입력 중인 내용을 취소하거나 열려 있는 설정 창 및 메뉴를 닫습니다.

**주요 슬래시 명령어**

* **`/connect`**: AI 제공자(Provider)를 새로 연결하거나 로컬 Ollama 모델 관련 설정을 변경할 때 사용합니다.


`opencode.json` 파일에 추가하여 유용하게 활용할 수 있는 주요 설정 옵션들입니다.

**권한(Permissions) 설정**
AI가 무단으로 파일을 수정하거나 위험한 터미널 명령어를 실행하지 못하도록 규칙을 걸어둘 수 있습니다. 예를 들어 특정 명령어는 반드시 사용자에게 물어보게(`ask`) 만들 수 있습니다.

```json
{
  "permissions": [
    {
      "action": "bash",
      "resource": "git push *",
      "effect": "ask"
    }
  ]
}

```

**감시 제외(Watcher Ignore) 설정**
빌드 결과물이나 임시 파일 폴더를 AI의 감시 대상에서 제외하여, 불필요한 파일 변화 감지로 인한 부하를 줄일 수 있습니다.

```json
{
  "watcher": {
    "ignore": ["dist/**", "build/**", "node_modules/**"]
  }
}

```

**스냅샷(Snapshots) 설정**
AI가 코드를 수정했을 때 원상복구(Undo/Revert)를 위해 파일 시스템 스냅샷을 남기는 기능을 켜거나 끌 수 있습니다. (기본값은 활성화되어 있습니다.)

```json
{
  "snapshots": true
}

```

**설정 파일 자동완성 및 검증 스키마 추가**
설정 파일 최상단에 스키마 주소를 넣어두면, 에디터(VS Code 등)에서 작성할 때 오타를 방지하고 자동완성 기능을 쓸 수 있습니다.

```json
{
  "$schema": "https://opencode.ai/config.json"
}

```
