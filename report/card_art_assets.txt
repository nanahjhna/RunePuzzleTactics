═══════════════════════════════════════════════════════════════════════════
1. 개요
═══════════════════════════════════════════════════════════════════════════

카드형 섹션(글래스 카드 / 9-slice 프레임 패널 / 다이얼로그) 뒤에 깔리는
**더미 배경·헤더 이미지** 16장. 실아트가 나오기 전까지 화면에
"이 자리에 이미지가 들어간다"는 감각을 심는 용도다.

- 생성 도구 : tool/gen_card_art.py  →  python tool/gen_card_art.py (멱등)
- 경로 상수 : lib/theme/ui_sprites.dart 의 kCardArt* (한 곳에 모음)
- 렌더 위젯 : lib/widgets/card_art.dart
    - CardArt.fill      : 프레임 전체를 덮는 배경
    - CardArt.header    : 상단 밴드(기본 높이 96px, 아래로 fade)
    - CardArtBackdrop   : 프레임이 없는 자리(다이얼로그 본체)에 아트를 깔기
- 층위      : 카드 배경색 → [카드 아트] → 9-slice 프레임 → 콘텐츠
- 파일 위치 : assets/ui_dummy/ (pubspec.yaml 의 폴더 선언으로 자동 포함)

4. 더미 규칙 / 유의사항
═══════════════════════════════════════════════════════════════════════════

1. **알파를 낮게 굽는다.** 기본 200/255 — 카드 배경색과 섞여 흰 텍스트가
   그 위에서도 읽힌다. 반투명 Material 뒤에 깔리는 cardart_gacha_dialog 만
   240 으로 올려 뚫고 보이게 한다.
2. **라운드 마스크가 이미지에 굽혀 있다.** UiFrame 은 Stack 을 직각으로
   클립하므로 모서리 알파가 0 으로 빠지는 마스크를 이미지에 굽는다.
   다이얼로그 형태 반경이 바뀌어도 이미지를 다시 만들 필요가 없다.
3. **헤더형은 아래로 fade.** 아래 40% 구간 알파를 255 → 0 으로 흘려
   "상단 밴드"로만 읽힌다. 기본 높이는 위젯 인자 height (기본 96px).
4. **9-slice 가 아니다.** BoxFit.cover 로 늘려 쓰므로 슬라이스 재측정이
   필요 없다. 실아트 교체 시 **경로 상수만** 바꾸면 된다.
5. **재생성은 멱등.** python tool/gen_card_art.py 를 다시 돌리면 같은
   파일을 덮어쓴다. 규격 변경은 스크립트의 SPECS(크기/액센트/패턴/알파)만.

── 교체 절차 (실아트 확보 시) ──────────────────────────────────────────────
  1) assets/ui_dummy/cardart_*.png 를 같은 **비율**의 실아트로 교체
     (또는 lib/theme/ui_sprites.dart 의 경로 문자열만 실아트로 변경)
  2) 알파 없는 실아트일 때는 모서리 페이드를 따로 넣어야
     카드 코너가 각져 보이지 않는다
  3) 나머지 호출 코드(각 화면 art: 인자)는 건드릴 필요 없음
  4) 새 섹션 추가 시: 스크립트에 CardArtSpec 추가 → 실행 →
     ui_sprites.dart 에 kCardArt 상수 추가 → 화면에 art: 인자 연결

── 패턴/색상 구성 (화면 성격 구분용) ─────────────────────────────────────
  · colors : AppColors 포인트 컬러(골드/블루/레드/퍼플/그린)를 다크
             인디고(BASE_TOP/BASE_BOTTOM)로 섞어 사용
  · patterns: stripes(대각선, 역동성) / scan(스캔라인, 목록·요약) /
             lattice(마름모, 뽑기·편성) / dots(도트, 정보) /
             arcs(동심호, 영웅·가차)
