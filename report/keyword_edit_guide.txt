[0] 시작 전 공통 규칙 (절대 기억할 것)
--------------------------------------------------------------------------------
1. 엔진 로직(수치·턴·퍼즐)은 lib/game/rune/ 아래 "순수 Dart" 파일에만 둔다.
   화면(Flutter/Flame)에는 UI/연출만 넣는다.
2. 새 엔진 파일을 만들면 반드시 lib/game/rune.dart(barrel)에 export 추가.
3. ValueKey / 콜백 이름 / 라우트 경로 / l10n 키는 함부로 바꾸지 않는다.
   (테스트와 다른 화면이 의존함. 예: 'stage-prep-dialog', 'timer_seconds' 등)
4. l10n(번역) 문구를 추가할 때는 en/ko/ja 3개 언어 키를 반드시 세트로.
5. 수정 후: flutter analyze → flutter test → flutter build apk --debug.
   (기존 테스트를 고치지 말 것. 14개 기존 실패는 별도 작업임)
6. 리드미/문서/버튼 레이아웃 참고: .opencode\plan\button_layout_reference.txt

[2] 핵심 파일 상세 — 여기까지만 보면 대부분 됨
--------------------------------------------------------------------------------
■ lib\game\rune\battle_engine.dart  ← "턴/타이머" 전부 여기
  - _deadline (71행): 현재 턴의 종료 시각.  null = 타이머 없음.
  - _startPlayerTurn() (117행): 턴 시작 → phase=plan, 입력 해제,
                               _deadline = now + playerActionTime (10초 자동 가동).
  - startPlayerTurn() (128행): 공개 래퍼. Flame이 몬스터 연출(0.8초) 끝나고 호출.
  - onFirstTouch() (~132~137행): PLAN→ACTION 전환만. 타이머는 위에서 이미 가동.
  - tick() (169행): 매 프레임 호출. deadline 지나면 timeout 처리(timeout phase).
  - 몬스터 턴 처리 (~360~396행): 파티 HP 감소는 즉시 적용(동기), phase는
    plan으로 끝나고 deadline은 null → Flame이 새 턴을 시작시킴.
  - 파티 HP <= 0 → phase = defeat (358행 부근).

■ lib\game\rune\stage.dart
  - StageConfig.playerActionTime (32행): "10초"를 바꾸고 싶으면 이 값.
  - actionTimeFor(stageNumber) (104행): 스테이지별 시간 계산.

■ lib\game\rune\battle_state.dart
  - enum BattlePhase (9행): plan/action/inputResolving/.../timeout/monsterTurn 추가 제거.
  - class BattleState (23행): 파티 HP, 울트라 게이지 등 상태 필드.

■ lib\screens\rune\rune_battle_game.dart  ← "Flame 전투 루프/연출"
  - _monsterTurnDuration = 0.8 (78행): 몬스터 공격 연출 길이.
  - _tickBattle() (191행): 매 프레임 battleEngine.tick() 호출(요구사항).
  - _advanceMonsterTurn(dt) (225행): 연출 중 phase=monsterTurn 표시, 끝나면
    battle.startPlayerTurn() (240행).
  - isIdle (81행): !_monsterAnimating 포함. "입력 가능한지" 판정.
  - 궁극기/입력 처리 (~399~427행).

■ lib\screens\rune\rune_battle_view.dart  ← "전투 HUD"
  - _onHud (352행), needsRefresh (359행): phase==plan 포함 → 카운트다운 실시간 갱신.
  - _startReadyCountdown (340행), _buildReadyOverlay (1101행): Ready...GO!
  - 타이머 바 전체 폭 UI (815~940행): 남은 시간 숫자 + 색상 진행 바.
  - _timerLevel (1267행): 남은 시간 3초 이하 빨강 등 색 규칙.

■ lib\screens\rune\rune_main_screen.dart  ← "허브(로비)"
  - _startBattle (115행): 출전 확인 → 플레이 소모 → 배틀 라우팅.
  - goToShop (163~175행): 결과에서 상점 이동 시 popUntil (검은 화면 수정 핵심).
  - AdBannerWidget (360행): 배너 광고는 BackdropFilter 밖에 배치.

■ lib\widgets\glass_surface.dart
  - blur <= 0 이면 BackdropFilter 생략 (검은 화면 수정의 핵심).
■ lib\widgets\monster_sprite.dart
  - phase == monsterTurn 일 때 공격 모션 재생 (Flame 0.8초 연출 때 관측됨).
■ lib\theme\app_theme.dart
  - 색 토큰: 배경 0xFF12131C, 유리 0x26FFFFFF, 골드 0xFFFFB300,
    CTA 그라디언트 [0xFFFF7E5F, 0xFFFF2525], radius 16/24/50.
■ lib\main.dart
  - FlutterError.onError (debug 전용 에러 표시 → 검은 화면 디버깅에 사용).
■ lib\l10n\app_strings.dart
  - 모든 문구. 키 추가 시 en/ko/ja 반드시 3개 세트.
