10. 참고 사항
════════════════════════════════════════════════════════════════════════════

- ui_dummy 스프라이트는 전부 흰색이라 런타임 틴트로 재사용도가 높음
- UI_Flat 이미지는 색상이 박혀 있어 틴트 불가
- tile_frame 계열은 배경이 투명하며, rune_grid.dart에서 background 파라미터로 배경색 전달
- 조준 하이라이트(rune_battle_game.dart:1447)는 동적 맥동 효과라 Canvas 직접 그리기 사용
- pubspec.yaml은 개별 파일 지정으로 변경되어 미참조 파일이 번들에 포함되지 않음
- hero 이미지는 속성별로 색상 토큰이 다르며, face/full/damage_full 3종류가 있음
- card 배경은 속성별로 색상이 다르며, 투명 영역이 많음
- monster 스프라이트는 141×192 크기의 세로 긴 슬라임 형태
- rune_row4.png은 512×59 크기의 가로 스프라이트 시트
- assets/effects/ 폴더는 5543장이 있지만 pubspec.yaml에 2개 폴더만 선언되어 있음 (미사용 에셋 다수 존재)
